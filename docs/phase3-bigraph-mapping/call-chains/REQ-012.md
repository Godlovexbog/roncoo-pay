# 调用链详情: REQ-012 条码支付-执行支付

## 入口方法
`RpTradePaymentManagerServiceImpl.getF2FPayResultVo()` (L223-L310)

## 调用链

```
getF2FPayResultVo()
├── 设置订单支付类型和通道信息
│   └── rpTradePaymentOrder.setPayTypeCode/payWayCode/payWayName
│   └── rpTradePaymentOrderDao.update(order)              // 更新订单 [SUPPORTING]
│
├── sealRpTradePaymentRecord(...)                         // 封装支付记录 [CORE]
│   └── buildNoService.buildTrxNo()                       // 生成平台交易流水号
│   └── buildNoService.buildBankOrderNo()                 // 生成银行订单号
│   └── 计算平台收入/成本/利润
│   └── new RpTradePaymentRecord()                        // 创建支付记录实体
│
├── rpTradePaymentRecordDao.insert(record)                // 保存支付记录 [SUPPORTING]
│
├── [IF 微信支付]
│   ├── rpUserPayInfoService.getByUserNo(...)             // 获取商户微信配置 [SHARED]
│   ├── WeiXinPayUtil.micropay(bankOrderNo, productName, amount, ip, authCode)  // 调用微信API [SHARED]
│   ├── [IF 返回结果为空]
│   │   └── rpNotifyService.orderSend(bankOrderNo)        // 发起轮询通知 [SHARED]
│   └── [IF 验签成功]
│       ├── [IF 通讯成功且业务成功]
│       │   └── completeSuccessOrder(record, transaction_id, timeEnd, msg)  // 成功处理
│       ├── [IF 支付失败]
│       │   └── completeFailOrder(record, err_code_des)   // 失败处理
│       └── [IF 结果未知]
│           └── rpNotifyService.orderSend(bankOrderNo)    // 发起轮询通知 [SHARED]
│
└── [IF 支付宝支付]
    ├── rpUserPayInfoService.getByUserNo(...)             // 获取商户支付宝配置 [SHARED]
    ├── AliPayUtil.tradePay(bankOrderNo, authCode, productName, amount)  // 调用支付宝API [SHARED]
    └── rpNotifyService.orderSend(bankOrderNo)            // 统一发起轮询通知 [SHARED]
```

## 业务规则

1. **实时返回**: 条码支付是实时支付，微信micropay直接返回结果
2. **结果未知时轮询**: 微信返回空结果或USERPAYING/SYSTEMERROR时，发起订单轮询
3. **支付宝统一轮询**: 支付宝条码支付统一通过订单轮询确认结果
4. **签名校验**: 微信返回结果必须验签

## 数据读写

- WRITE: `rp_trade_payment_order` (update支付类型和通道)
- WRITE: `rp_trade_payment_record` (insert新记录)
- READ: `rp_user_pay_info` (获取商户支付渠道配置)
