## 全景图校对

对 `docs/biz-loop/panorama/` 下已完成的基础文件做交叉校对和质量检查。

### 检查项

**1. API vs 数据模型**

提取 api-list.md 中所有接口入参/出参的对象名，在 data-model.md 中搜索这些对象的定义：
- "接口引用了未建模对象: XxxResponse"
- "数据模型中有未使用的对象: XxxVo"

**2. 依赖 vs 配置**

检查 external-deps.md 中的 HTTP 外部服务是否在 config.md 中有对应配置项。

**3. 规则 vs 代码一致性（新增）**

- 扫 `rules/methods/` 下所有方法文件的"提取质量"章节
- 汇总统计: 总决策点数 / 提取规则数 / 转化率 / 低置信度规则(<0.5)
- 对低置信度规则，抽查源码验证规则描述是否与代码一致
- 报告: "规则提取覆盖率 N%, K 条低置信度规则需人工审核"

**4. 流程完整性**

- 读 flow-maps.md，提取所有入口端点路径
- 读 api-list.md，检查 flow 中引用的入口是否在 API 清单中
- 读 flow-maps.md 中的"决策"步骤，检查是否有对应的规则方法文件
- 报告: "M 个入口端点, N 个有对应API, K 个决策节点有对应规则"
