# 调用链详情: REQ-011 条码支付-订单管理

## 入口方法
`RpTradePaymentManagerServiceImpl.f2fPay()` (L165-L214)

## 调用链

```
f2fPay()
├── PayTypeEnum.getEnum(payType)                          // 验证交易类型
├── PayWayEnum.getEnum(payType.getWay())                  // 获取支付方式
├── rpPayWayService.getByPayWayTypeCode(...)              // 获取费率配置 [SHARED]
├── rpUserPayConfig.getUserNo()                           // 获取商户号
├── rpUserInfoService.getDataByMerchentNo(merchantNo)     // 获取商户信息 [SHARED]
├── rpTradePaymentOrderDao.selectByMerchantNoAndMerchantOrderNo()  // 查询订单 [SUPPORTING]
├── [IF 订单不存在]
│   └── sealF2FRpTradePaymentOrder(...)                   // 封装订单数据 [CORE]
│       └── buildNoService.buildBankOrderNo()             // 生成银行订单号
│       └── buildNoService.buildTrxNo()                   // 生成交易流水号
│       └── new RpTradePaymentOrder()                     // 创建订单实体
│   └── rpTradePaymentOrderDao.insert(order)              // 保存订单 [SUPPORTING]
└── getF2FPayResultVo(...)                                // 执行支付 → 见 REQ-012
```

## 业务规则

1. **订单幂等**: 同一(商户号+商户订单号)只能有一个活跃订单
2. **金额校验**: 已存在订单的金额必须与传入金额一致
3. **状态校验**: 已支付成功的订单不能重复支付
4. **类型校验**: 只支持 MICRO_PAY(微信刷卡) 和 F2F_PAY(支付宝条码)

## 数据读写

- READ: `rp_trade_payment_order` (selectByMerchantNoAndMerchantOrderNo)
- WRITE: `rp_trade_payment_order` (insert, 当订单不存在时)
- READ: `rp_user_info` (getDataByMerchentNo)
- READ: `rp_pay_way` (getByPayWayTypeCode)
