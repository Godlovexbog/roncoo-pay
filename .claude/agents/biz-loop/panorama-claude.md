## 生成路由型 CLAUDE.md

读 `docs/biz-loop/panorama/` 下产出文件，生成**精简路由型** CLAUDE.md 到**项目根目录** `CLAUDE.md`。
CLAUDE.md 是导航入口，不是知识库——每个章节点到为止，用链接指向详细文档。

### 硬性限制（违反即为失败）

| 规则 | 要求 |
|------|------|
| 总行数 | **≤200 行**（不含 GitNexus 自动注入块） |
| 每章行数 | 除架构图外，每章 ≤15 行 |
| 表格 | 只允许 3 处：模块速览（≤10行）、启动命令（≤10行）、配置文件速查（≤8行）。其他章节**禁止表格** |
| 外部依赖 | **只列名称**，≤5 行。禁止列出连接字符串、队列名、IP/端口 |

### 章节结构（每章含行数上限）

**项目定位** (≤3行)
- 1-2 句说清项目是什么 + 1 行链接

**核心架构** (≤20行)
- ASCII 分层图 + 每层一行职责
- → `[architecture.md](...)`

**模块地图** (≤25行)
- 子域速览表（≤8行）+ 模块速览表（≤10行）
- → `[architecture.md](...)`

**关键约定** (≤20行)
- 命名模式 3 行 + 分层调用链 1 段 + 关键约束 5 条
- → `[config.md](...)`

**怎么跑** (≤25行，含代码块)
- 编译命令 1 行 + 数据库初始化 1 段 + 启动命令表（≤10行）
- 冒烟 URL 3-5 行 + 配置文件位置速查表（≤8行）
- → `[env/setup.md](...)`
- **禁止**: 环境要求说明块、数据库连接详情、密码/账号信息

**外部依赖** (≤5行)
- 支付通道: 仅列名称。格式: "微信支付（统一下单/被扫/查询/对账单）、支付宝（PC网页/被扫/查询）"
- 中间件: 仅列名称+用途。格式: "MySQL（Druid连接池）、ActiveMQ（2个队列）、Ehcache（Shiro权限缓存）"
- → `[external-deps.md](...)`
- **绝对禁止**: 连接字符串、队列名称、IP/端口、broker URL

**禁区 / 历史包袱** (≤3行)
- 留空，标注"待补充"

**相关文档** (≤10行)
- panorama/ 下所有 .md 文档链接，每行一个

### 自检清单（输出 CLAUDE.md 前必须逐条确认）

- [ ] 总行数 ≤200？
- [ ] "外部依赖"有无连接字符串/队列名/端口？（有→删除）
- [ ] "怎么跑"有无环境要求说明块？（有→删除）
- [ ] 每个章节最后一行是 `详见 xxx.md` 链接？
- [ ] chapter 下的子标题是否仅用 `###`（不用 `####` 及更深，保持章节扁平）？

### 核心原则

1. **路由优先**: 每个章节回答"这是什么 + 去哪看详情"，不回答"全部有哪些"
2. **不复制表格细节**: 已有文档的完整表格不复制，只列 3-5 条代表性条目
3. **不列全量清单**: API 清单、全量配置项、全量依赖表一律不出现
4. **链接兜底**: 每个章节必须有一个指向 panorama/ 的链接
