## 生成路由型 CLAUDE.md

读 `docs/biz-loop/panorama/` 下产出文件，生成**精简路由型** CLAUDE.md 到**项目根目录** `CLAUDE.md`（≤300 行）。
CLAUDE.md 是导航入口，不是知识库——每个章节点到为止，用链接指向详细文档。

### 章节结构

**项目定位** (2-3行)
- 从 architecture.md 提取项目名称 + 技术栈 + 一句话定位

**核心架构** (≤20行)
- ASCII 分层图 + 每层一句话职责
- 链接到 architecture.md

**模块地图** (≤30行)
- 表格: 模块名 / 端口 / 一句话职责 / 链接
- 三类: 业务服务层 / 表现层(web) / 应用层(app)

**关键约定** (≤30行)
- 命名规范: 仅列核心模式（XxxDao/XxxService/XxxController 等），不列全量示例
- 分层调用链: 一行箭头链
- 配置加载方式: 一句话概括
- 关键约束: 3-5 条最重要的（如"无环境区分"、"ActiveMQ连接池硬编码"）
- 链接到 config.md

**怎么跑** (≤40行)
- 环境要求: 4 行
- 编译: 1 行命令
- 启动: 表格（顺序/模块/端口/命令）
- 冒烟: 核心 URL 列表
- 配置文件位置速查: 表格
- 链接到 env/setup.md

**外部依赖** (≤20行)
- 支付通道: 仅列名称（微信支付/支付宝）
- 中间件: 仅列名称+用途（MySQL/ActiveMQ/Ehcache）
- 链接到 external-deps.md

**禁区** (留空)
- 标注"待补充"

**历史包袱** (留空)
- 标注"待补充"

**相关文档** (≤10行)
- panorama/ 下所有 .md 文件链接列表

### 硬约束

1. **总行数 ≤ 300 行**
2. **每个章节必须包含链接**指向 panorama/ 下对应详细文档
3. **不复制表格细节**: 已有文档的完整表格不复制，只列 3-5 条代表性条目 + "详见 xxx.md"
4. **不列全量清单**: API 清单、全量配置项、全量依赖表一律不出现
5. **路由优先**: 每个章节回答"这是什么 + 去哪看详情"，不回答"全部有哪些"
