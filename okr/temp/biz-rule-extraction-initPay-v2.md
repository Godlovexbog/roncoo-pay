> 基于 DDD 元素分析文档中的事件、实体、流程，按 SBVR 分类体系逐类检查代码实现
> 审查范围: initPay 方法完整调用链
> 数据来源: biz-flow-graph-initPay-v2.md

## 一、规则分类理论与检查方法

```
理论框架 (SBVR 12 类规则体系)
        │
        ▼
    12 类规则检查清单
        │
        ▼
  ┌─────────────────────────────────────────────────────────┐
  │  对每一类规则，检查:                                      │
  │  1. 理论要求: 该类规则在业务中应覆盖什么                    │
  │  2. 代码现状: 从实体属性、流程决策点、事件条件倒推已实现部分  │
  │  3. 缺失识别: 理论上应有但代码中找不到对应实现               │
  │  4. 风险定级: P0(数据安全/资金) > P1(业务逻辑) > P2(健壮性) │
  └─────────────────────────────────────────────────────────┘
```
